## P1 — Uncommitted Hotfixes (CC8.1 Drift Resolution)

Two production hotfixes were applied as working-tree changes on HEAD `60cf09e`.
These are now committed to branch `fix/rag-prod-lt01-20260807` and merged to `main`.

### Hotfix 1: Qdrant SSL WRONG_VERSION_NUMBER

**File**: `src/app/services/vectorstore.py`

```
fix(vectorstore): force https=False when RAG_INTERNAL_TLS_ENABLED=false

qdrant-client 1.12.1 silently upgrades to HTTPS when api_key
is present. This causes SSL WRONG_VERSION_NUMBER on internal
segments without TLS. Explicit kwargs override preserves
internal plaintext while allowing TLS segments to function.

Ref: Deployment Record rag-prod-lt01 2026-08-07
```

### Hotfix 2: Embedding Model Cache (Read-Only Rootfs)

**File**: `src/Dockerfile` + `ansible/roles/rag_service/templates/docker-compose.yml.j2`

```
fix(dockerfile): bake embedding model into container image

Pre-downloads sentence-transformers/all-MiniLM-L6-v2 at build
time into /app/.cache/huggingface. Eliminates runtime dependency
on HuggingFace Hub availability — if the library cache misses,
a restart with no internet would leave the RAG stack non-functional.

Dockerfile ENV sets HF_HOME and SENTENCE_TRANSFORMERS_HOME to
the baked cache path. Removed compose-level overrides that
redirected to tmpfs (no longer needed — model is in the image
layer, not downloaded at runtime).

Ref: Deployment Record rag-prod-lt01 2026-08-07 (P2 finding)
```

### Hotfix 3: Secret Masking in Audit Logs

**File**: `src/app/audit.py`

```
fix(audit): add credential masking to structlog and JSONL output

Prevents REDIS_URL, DATABASE_URL, and other credential patterns
from appearing in stdout logs or the append-only audit JSONL
file. Catches URL-embedded credentials (scheme://user:pass@host)
and known secret field names (redis_url, jwt_secret, etc.).

SOC 2 CC6.1 / GDPR Art. 32 — credential leakage prevention.

Ref: Deployment Record rag-prod-lt01 2026-08-07 (P0 incident)
```
